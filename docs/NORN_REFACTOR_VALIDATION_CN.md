# NORN 重构验证记录

日期：2026-11-03。环境：CPU，Python 3.11，PyTorch 2.5.1+cu121；当前进程没有可用 CUDA。默认 SFNO 和已有 schema-2 checkpoint 的语义保留；新增模型和生成入口均为实验性。

## 已完成的功能

- 统一模型工厂：SFNO、gated SFNO、函数化 Tucker 共用训练、恢复、独立推理及导出入口。
- 球面坐标／动态几何因子与低维核心；以 Ma 为单位的 GP 时间先验、显式 km 输出尺度及单次核心正则。
- 冻结解码器下的 GP-pCN 条件广义后验，保存潜变量、坐标、分位区间及链诊断。
- 独立历史集合编码；父历史组隔离、重复序列检查、潜变量坐标系及几何指纹约束。
- 基于 GP 白化核心的序列扩散训练和近似观测引导，完整年龄混合似然参与梯度。
- 整年龄区间留出／宽年代 buffer、可选真实来源分组、prepared 划分配置一致性检查。
- 加入观测噪声和年龄混合的预测评估，区分潜在厚度区间和观测预测区间。

## 软件验证

执行命令：

```bash
.venv/bin/python -m pytest -q tests --disable-warnings --maxfail=2
.venv/bin/python -m ruff check src/norn_earth tests examples
git diff --check
```

提交前复核后，19 项测试通过；静态检查和 diff 检查通过。测试涵盖缓存／重算梯度与直接反传一致、GP 正则只反传一次、年龄混合而非年龄均值似然、未观测时刻的信息传播、训练／留出标签隔离、整年龄区间排除、来源分组、旧 SFNO 配置 checkpoint 加载、恢复训练与导出、CPU 预测评估、扩散标准化隔离及潜变量指纹检查。新增回归检查包括 holdout 文件迁移后的 dataset 哈希、无效集合不写出、零权重查询角点及缺测区面积权重；异常扩散能量和标准化参数也受到检验。

其中 pCN 算法单独在具有解析解的二时刻高斯逆问题中检验后验均值、协方差和未观测时刻的信息传播；真实 NORN 的广义后验仍需要另行检查收敛及适用性。

## 可复现的合成闭环

```bash
.venv/bin/python examples/generative_demo.py \
  --output outputs/refactor_validation_20261103_v2 \
  --steps 100 --prior-steps 200 --encoding-steps 100 --device cpu
```

实际产物位于 `outputs/refactor_validation_20261103_v2/`，不纳入源码版本管理。主要结果文件：

- `comparison.json`：固定协议下的模型对照及先验去噪验证。
- `functional_tucker/best.pt`、`sfno/best.pt`：根据验证 MAE 选择的 checkpoint。
- `prediction/thickness.npz`、`prediction/thickness.nc`：包含非整数年龄 13.4 Ma 的独立导出。
- `gp_posterior/`、`diffusion_posterior/`：核心样本、Gauss 网格汇总及来源／采样元数据。
- `field_ensemble.npz`、`latent_ensemble.npz`、`diffusion_prior.pt`：独立解析历史、共享坐标系核心及已训练先验。
- `gp_validation.json`、`diffusion_validation.json`：仅验证记录的预测分布评估。

合成数据采用 8×16 内部网格、0–60 Ma 每 10 Ma 锚点，现代参考依然来自原生现代数据格式。测试窗固定为 25–35 Ma；164 条训练、18 条验证、33 条测试、25 条宽年代 buffer，现代端点允许使用。两个神经模型各训练 100 步，使用相同输入、数据划分和验证选模。Tucker 额外使用权重为 0.001 的核心 GP 正则；它是架构／正则对照，不是严格等参数或等算力比较。

| 模型 | 参数量 | 验证 MAE（km） | 时间窗测试 MAE（km） | 已知完整合成场面积加权 RMSE（km） |
|---|---:|---:|---:|---:|
| 现代参考直接回用 | — | 0.7124 | 0.6526 | 0.7211 |
| SFNO | 5,121 | 0.1207 | 0.1048 | 0.0857 |
| 函数化 Tucker + GP 正则 | 164 | 0.1373 | 0.1019 | 0.0484 |

验证集上 SFNO 更好，默认模型保持 SFNO。单个简单解析例子上的测试／完整场差异不能证明新方法优于 SFNO，更不能外推为真实古厚度精度。

扩散先验使用 12 条独立解析历史（8 条训练、4 条验证），各自有独立斜率／空间相位、相同条件几何。仅约 10% 空间点可见，交错年龄整层缺测；每条历史编码 100 步，扩散训练 200 步。固定验证扰动下，去噪 MSE 从 0.2174 降至 0.1372。该指标用于验证学习和选模，不是物理场精度或概率校准证据。

## 采样诊断与证据边界

快速闭环中的 GP 链每链仅保留 8 个样本，接受率约 0.446，但最大基础 split R-hat 为 9.35，**混合尚未建立**。此运行只验证程序路径；其预测区间和均值不用于支持科学结论。扩散闭环仅生成 4 条历史，是近似条件采样，也不构成校准证据。

另执行了较长 GP 检查：两链各 1,000 步 warmup、保留 400 个样本、间隔 5、`beta=0.3`，共每链 3,000 次迭代。接受率分别为 0.242、0.235，最大基础 split R-hat 降至 1.299，仍标记 `mixing_not_established`，不能把这次结果当作收敛后验。产物位于 `gp_longer_run/`。这是当前明确的推断限制，而非已解决的校准结果。

GP 采样以单位白化高斯先验和按记录／区块归一的数据能量定义广义后验；其权重语义与点估计训练的弱 GP 正则不同。已拟合因子固定，因子、板块重建、代理转换的不确定性未纳入。预测覆盖率只针对带年龄和观测噪声的合成记录，不能视为真实地壳厚度的置信覆盖率。

本轮没有启动真实古厚度训练：工作区未提供真实观测、现代 DAT 与匹配板块输入。后续真实研究需要核验代理来源／标定关系、使用研究来源独立和区域留出的证据、检验 GP 长度尺度／秩／先验敏感性，并完成独立地质案例验证。不同板块几何的集合先验、全表示不确定性以及 SDIFT 的闭式 MPDPS 均不在本轮已实现范围内。
