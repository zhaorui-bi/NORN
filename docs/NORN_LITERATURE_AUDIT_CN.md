# NORN 与 CRAI／SDIFT 的提交前核查

日期：2026-11-03。结论：当前代码可作为实验性研究软件发布；已有的合成自检不能升级为真实古厚度精度、严格物理一致性或已校准后验的证据。SFNO 继续作为默认对照。

## 来源与实际阅读范围

- Kadow, Hall & Ulbrich (2020)，[Artificial intelligence reconstructs missing climate information](https://www.nature.com/articles/s41561-020-0582-5)，Nature Geoscience 13, 408–413，DOI: 10.1038/s41561-020-0582-5。核查范围为出版社公开摘要、扩展图说明、[作者海报](https://events.ecmwf.int/event/172/contributions/1755/attachments/873/1546/Machine-Learning-WS_Kadow.pdf)及[官方仓库](https://github.com/FREVA-CLINT/climatereconstructionAI)；本次没有获得订阅正文及完整补充材料，因此不声称逐项复现了原实验。
- Chen et al. (2025)，[Generating Full-field Evolution of Physical Dynamics from Irregular Sparse Observations](https://arxiv.org/html/2505.09284v3)，NeurIPS 2025，arXiv:2505.09284v3。核查了方法 §3、实验 §5、附录 D/E 的训练和条件引导步骤、附录 G.5 的噪声消融及附录 H 的限制，并与[官方仓库](https://github.com/OceanSTARLab/SDIFT)的阶段划分对照。本轮没有重新运行其三个原始基准。

## 方法对应关系与不成立的等同

| 核查点 | NORN 的实现与可核验范围 |
|---|---|
| CRAI 的缺测重建验证 | 合成对照保留全场误差，另按训练查询的实际插值支持排除已受监督格点，单独计算剩余格点的面积加权误差；现代条件输入仍保留。不是完全未见现代资料的实验。 |
| 原始气候数据的可用性 | 没有把现代厚度沿板块搬运的输入当作真实古厚度标签；真实资料仍为 `unverified_proxy`。 |
| SDIFT 的函数化 Tucker 表示 | NORN 的两个因子模式是球面嵌入与年代几何条件，核心形状为年龄×空间秩×条件秩。这是适配，不是原文各笛卡尔维度分解的复现；没有将其普适逼近定理直接套用于当前固定秩模型。 |
| 连续坐标和动态生成 | 低秩因子函数可连续求值，但公共厚度接口继续使用锚点与空间插值；扩散先验绑定同一套年代和几何。没有宣称任意分辨率上的独立地质恢复能力。 |
| GP 序列噪声 | 在固定年代集合上以 $W=Lz$ 白化核心，对 $z$ 进行扩散，再经 $L$ 解码；需要多条独立历史共享同一潜变量坐标系。它与原文直接对核心加 GP 噪声的网络和去噪目标不同。 |
| SDIFT 的 MPDPS | 未实现原文通过 GPR 构造跨时刻伪核心及闭式高斯引导的全部步骤。当前是经正厚度变换与年代混合似然自动微分的有界启发式引导，标记为近似条件生成。 |
| 贝叶斯与区间 | GP-pCN 以显式广义后验为目标；扩散引导无 MH 校正。因子权重、板块模型、代理转换的全部不确定性均未纳入，输出不称作校准置信区间。 |
| 显式物理约束 | 平滑 GP 不能替代质量守恒；SDIFT 附录 H 也将缺乏显式物理定律列为限制。NORN 继续以单独的 `physics` 对照声明物理先验，当前潜变量采样的数据能量不包含物理项。 |

## 两个可手算的实现检查

取空间秩和条件秩均为 2，$f=(1,2)$、$q=(1,3)$、$W=\operatorname{diag}(0.1,0.2)$，则 $f^\top Wq=0.1+1.2=1.3$。当 `latent_scale_km=10`、基准原值 $b=0$、$\epsilon=0.5$ km 时，原值为 $10/\sqrt{4}\times1.3=6.5$，输出厚度为 $0.5+\operatorname{softplus}(6.5)\approx7.0015$ km。代码的缩放、核心收缩和正值变换与这一表达一致；这只检验表示，不证明观测能够唯一确定 $W$。

略去仅用于数值稳定的对角抖动，取二时刻相关矩阵 $K=\left[\begin{smallmatrix}1&0.8\\0.8&1\end{smallmatrix}\right]$，可取 $L=\left[\begin{smallmatrix}1&0\\0.8&0.6\end{smallmatrix}\right]$。白噪声 $z=(1,-1)$ 经映射得到 $W=(1,0.2)$；$LL^\top=K$。这说明时间相关性经白化坐标传递，但不构成原文 MPDPS 的等价性证明。单独的解析高斯逆问题测试核对了 pCN 条件均值和协方差。

## 已修复及补充检查

1. **来源哈希错误**：搬迁 holdout CSV 时，局部变量可能覆盖 dataset 路径，导致返回错误的数据哈希。已分离变量并加入搬迁回归测试。
2. **无效集合的发布**：集合编码现在先验证父历史分组约束和重复核心，再写输出；不会先生成一个校验失败的集合文件。物理历史是否真正独立仍需数据提供方核实。
3. **非有限概率结果**：扩散训练／采样检查白化核心、标准化参数、验证损失和条件能量；后验解码检查厚度有效性。异常结果不会被当作正常区间保存。
4. **评价中的诊断丢失**：预测评估报告保留原采样方法与链诊断，使未建立混合的采样结果可追溯。
5. **全场均分掩盖缺测误差**：新增固定训练支持掩膜、零权重插值角点检查及缺测区面积加权指标。掩膜只依赖训练／现代监督，不按模型误差挑选。
6. **后续提交的持续验证**：新增锁定 CPU 依赖的 GitHub Actions，覆盖 Python 3.9／3.11，并在 3.11 上运行完整生成入口的合成冒烟流程。

## 尚未解决的科学问题

原有短链及较长 GP 试验均未建立混合，最大基础 split R-hat 分别为 9.35 与 1.299；不能称作收敛后验。真实资料的来源核验、独立区域与研究来源验证、先验／秩敏感性、多随机种子对照、原始论文基准复现及真实板块几何的端到端新实验仍须另做。论文中的数值优势不自动转移到 NORN。

软件检查与本轮补充合成结果见 [验证记录](NORN_REFACTOR_VALIDATION_CN.md)。发布此版本表示实验入口和已执行的软件检查可审查，不表示上述科学问题已经解决。
